## Technical Foundation

All opus/ files leverage the **String Engine** framework ([reference](../whatami/STRING_ENGINE_TECHNICAL_REFERENCE.md)):

- **Karplus-Strong Algorithm**: Physical string modeling via delay-line feedback
- **Formant Filters**: Vocal tract simulation for naturalness
- **DSP Chains**: Distortion → Cabinet Filter → Delay → Reverb → Master
- **Web Audio API**: Native browser audio synthesis (no external samples)
- **Canvas Synchronization**: Real-time visualization tied to audio playback
- **Tone Recipes**: Pre-configured synthesis parameter sets for specific instruments
