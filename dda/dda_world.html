The "Decoupling" Theorem

The Inertia Paradox states that in recursive filters, Stability ($P_0$) and Lag ($\phi$) are coupled.

Classic EMA:   Fn = P0 · Fn-1 + (1-P0) · In

DDA v7.0 solves this by decoupling the loop into two paths:

  1. Inertial Path: Handles noise rejection ($P_0 = 0.7$)
  2. Pre-Cognitive Path: Cancels phase lag via a boosted trend vector ($\gamma \cdot \Delta_{filtered}$)
Ln = In + \gamma \cdot \text{Filter}(I_n - I_{n-1})
Fn = P0 \cdot k \cdot F_{n-1} + m \cdot Ln

class DDA {
  update(I_n) {
    // 1. Calculate Derivative
    let delta = I_n - this.prev_I;
    
    // 2. Input Noise Filter (The Shield)
    this.dF = this.alpha * delta + (1-this.alpha) * this.dF;
    
    // 3. Pre-Cognitive Boost (The Sword)
    // Unity Gain (I_n) + Boost (gamma * dF)
    let L = I_n + (this.boost * this.dF);
    
    // 4. Update Law
    let prior = this.P0 * this.k * this.prev_F;
    let F = prior + this.m * L;
    
    // 5. Adaptive Gain & State Rotation
    this._adapt(I_n, F);
    this.prev_I = I_n; this.prev_F = F;
    return F;
  }
}
