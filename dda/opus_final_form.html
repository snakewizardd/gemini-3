The Inertia Paradox

Every recursive filter faces an impossible trade-off. You can have stability OR speed — never both.

❌ High Inertia (P₀ = 0.9)

Smooth output, excellent noise rejection.
But: Severe phase lag. The filter reacts too slowly to track changes.

❌ Low Inertia (P₀ = 0.3)

Fast response, tracks changes instantly.
But: Amplifies noise. Output is jittery and unreliable.

Best of both worlds.

The DDA Solution

DDA v7.0:   Fn = P₀ · k · Fn-1 + m · [In + γ · Filter(ΔI)]
1

Calculate Derivative

Compute the change: ΔI = In - In-1

2

Filter the Noise (The Shield)

Low-pass filter the derivative to remove high-frequency noise:
Δfiltered = α·ΔI + (1-α)·Δprev

3

Pre-Cognitive Boost (The Sword)

Add a scaled trend prediction to cancel phase lag:
Ln = In + γ · Δfiltered

4

Recursive Bayesian Update

Combine prior (inertia) with likelihood (pre-cog):
Fn = P₀·k·Fn-1 + m·Ln

Production Implementation

class DDA {
    constructor(config) {
        this.P0 = config.p0 || 0.7;      // Inertia (stability)
        this.m = 1 - this.P0;            // Likelihood weight
        this.boost = config.boost || 0.6; // Pre-cognition factor
        this.alpha = config.filter || 0.1;// Derivative filter
        this.k = 1.0;                    // Adaptive gain
        this.prev_F = 0; this.prev_I = 0; this.dF = 0;
    }
    
    update(I_n) {
        // 1. Raw Derivative
        let delta = I_n - this.prev_I;
        
        // 2. Filter (The Shield) - Kill high-freq noise
        this.dF = (this.alpha * delta) + ((1 - this.alpha) * this.dF);
        
        // 3. Pre-Cognition (The Sword) - Cancel lag
        let L = I_n + (this.boost * this.dF);
        
        // 4. Recursive Update
        let F = (this.P0 * this.k * this.prev_F) + (this.m * L);
        
        // 5. State rotation
        this.prev_F = F; this.prev_I = I_n;
        return F;
    }
}
